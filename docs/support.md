# サポート

公開URL: https://shoma4646.github.io/guitar_lovers/support.html（gh-pagesブランチにHTML化して配置する）

Guitar Lovers（以下「本アプリ」）の使い方とよくある質問をまとめています。

## 使い方（3ステップ）

1. **動画を読み込む**: PracticeタブでYouTube動画のURL/IDを入力し、練習したい区間（A点/B点）を指定してABループ再生を確認する
2. **フレーズとして保存**: 区間・BPM・目標BPMを設定し、「フレーズとして保存」する
3. **練習を記録する**: 今日の練習メニューからフレーズをタップして反復練習し、結果（○/△/×）を記録する。次回の目標BPMが自動で更新される

## よくある質問

### 動画が埋め込み再生できません

動画の投稿者が埋め込み再生を許可していない場合、本アプリでは再生できません（YouTube側の制限のため、アプリ側で解除することはできません）。別の動画をお試しください。

### マイクの許可を求められます

チューナー機能でギターの音を拾うためにマイクを使用します。音声は端末内でピッチ検出に使われるのみで、保存・送信は行いません。許可しない場合、チューナー機能は利用できません。

### 保存したデータはどこにありますか

練習フレーズや練習記録は、サーバーではなく**お使いの端末内にのみ**保存されます。機種変更やアプリの再インストールを行うとデータは引き継がれません。
